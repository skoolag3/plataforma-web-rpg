# Artefatos de modelagem do AnimeCards

Esta pasta contém os diagramas atualizados conforme o relatório técnico `v0.12` e o código atual da plataforma.

## Arquivos

- `01-casos-de-uso-geral.puml`: atores e funcionalidades principais.
- `02-dominio-e-combate.puml`: entidades do domínio e relações do combate.
- `03-modelo-dados-relacional.puml`: visão relacional simplificada do banco.
- `04-contexto.puml`: usuários e serviços externos no contexto da plataforma.
- `05-containers.puml`: frontend, backend, banco e integrações.
- `06-componentes-backend.puml`: módulos e dependências internas da API.

Os arquivos `.puml` são fontes editáveis. As imagens `.png` de mesmo nome são geradas para inserção no relatório.

O Astah Community instalado nesta máquina permite abrir projetos `.asta`, mas sua API bloqueou a criação programática de elementos. Por isso, os artefatos foram produzidos em PlantUML, mantendo conteúdo e relações prontos para posterior reprodução ou importação em uma edição do Astah que aceite automação.
